# Employee Compensation Analysis

## Project Overview
This project analyzes employee compensation using MySQL.

## Key Analysis Areas
- Compensation Inequality
- Structural Pay Gaps
- Hiring-Sequence Salary Inversions
- Workforce Restructuring
- Compensation Rankings and Trends
- Executive Recommendations

## Tools Used
- MySQL
- SQL

## Project Objective
To identify compensation gaps, salary inconsistencies, and workforce-related compensation risks through SQL analysis.
